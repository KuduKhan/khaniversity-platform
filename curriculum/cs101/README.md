# CS101 · Content version 0.1.0

School: Computer Science → Program: Computer Science Foundations → Course: Introduction to Computer Science & Python → Module 01: Computer systems & computational thinking → Lesson: Computational thinking.

The published foundation lesson is rendered by `src/components/lesson.tsx`; catalog and formative questions live in `src/modules/academics/catalog.ts`. Outcomes: identify inputs/process/outputs, decompose a problem, write and trace a finite algorithm, test an edge case. No prerequisites. Estimated duration: 15 minutes.

Assessment: five formative questions, 80% mastery threshold, repeat attempts permitted, highest score retained. The migration's private scoring function holds the server-side answer key. Question changes require a corresponding versioned migration and content review; do not silently alter historical criteria.

Modules 02–10 are roadmap entries only. Full CS101 completion and capstone evaluation are outside Foundation 0.1. Instructional review by a pilot reviewer is still required before onboarding real learners.
